# AI 简历编辑器

当前版本：`v4.0`

这是一个可直接在浏览器运行的简历工作台。

编辑器内置宝蓝、青绿、紫罗兰 3 组配色，每组均提供浅色和深色版本。主题支持自动、浅色、深色三种模式；自动模式按浏览器本地时间在 `07:00` 切换为浅色、`19:00` 切换为深色。主题选择会保存在当前浏览器中，不影响简历预览和 PDF 的白底排版。

页面左侧提供工作区导航。“简历编辑”“职位推荐”和“面试闪卡”已可用；面试闪卡支持规定字段题库导入、结构化训练、追问、状态标记、训练统计和本地进度恢复。

## 打开

使用 Chrome 打开根目录中的 `index.html`。简历编辑可离线运行；匹配分析需要网络和有效的模型 API 配置。

在线版本：[GitHub Pages](https://whale8790-ux.github.io/resume-ai/)

数据与模型配置保存在当前浏览器的 `localStorage` 中，不会自动在电脑和手机之间同步。请勿在公共设备中保存 API Key。

## 项目结构

- `index.html`：唯一运行入口。
- `src/`：唯一业务源码目录。
- `assets/`：本地样式文件。
- `vendor/`：固定版本的第三方依赖。
- `dist/app.js`：由源码生成的浏览器脚本，不直接编辑。
- `scripts/build.js`：离线构建脚本。

## 修改源码

编辑 `src/` 中的文件后，在项目根目录执行：

```bash
node scripts/build.js
```

然后刷新 `index.html`。
